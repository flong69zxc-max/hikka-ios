# Hikka Wrapper for iOS

iOS-оболочка для запуска Python-юзербота Hikka через LiveContainer (без подписи).

## 📋 Требования

- macOS 13+
- Xcode 15+
- Python 3.10
- iPhone с установленным LiveContainer
